# Product

## Register

brand

## Users

Visitors are hiring managers, engineering peers, and the homelab/AI community checking out Matt Gibbs — engineering leader, problem solver, mentor. They arrive from GitHub, LinkedIn, or word of mouth, usually on one quick visit. The site is the proof-of-work: it should demonstrate craft, not just describe it.

## Product Purpose

Personal portfolio (v5.x → v6 redesign, a design pattern iterated for a decade). Showcases experience, projects, and technologies — and going forward, Matt's AI-augmented engineering practice as first-class content (the site itself is designed/built/operated with an agent fleet, which the "mainframe" conceit makes diegetically honest). Success: a visitor leaves thinking "this person builds distinctive, reliable things and clearly practices what they preach."

## Brand Personality

**Terminal-brutalist collage.** Technical, self-aware, warm, playful. Technical substance with human warmth and zine energy. Retro-hardware nostalgia (VHS, mainframe, phosphor) rendered earnestly, never cynically. Code IS the content — plausible bash/systemd output, never lorem ipsum.

## Anti-references

- Generic dark-SaaS hero (gradient blob + big number stats)
- Cold matrix-green hacker terminal; pure-black backgrounds
- Ghost-gray low-contrast text "for elegance"
- Template portfolio sites; anything that reads "AI made that"
- Motion for its own sake

## Design Principles

1. **Protect the fingerprint.** This is a sharpening of a decade-old identity, not a replacement. Don't templatize it.
2. **One element wins the eye per view.** Exactly one hot accent (sticker/label) per viewport; restraint inside the chaos.
3. **Diegetic honesty.** Terminal motifs must correspond to something real (real commits, real cluster, real agents) — never decorative fakery.
4. **Warmth over cold.** Warm charcoal base, amber mono, marker-script humanity against the monospace.
5. **See it to ship it.** Every visual change is verified in a real browser at 1280 and 390 widths before it lands.

## Accessibility & Inclusion

- WCAG 2.1 AA (per ANTIGRAVITY.md standards); keyboard navigation verified on all interactive elements
- Accessible contrast is non-negotiable — no ghost-gray text
- `prefers-reduced-motion` alternatives for all animation (CRT/VHS effects already have a global toggle; keep it)
- Semantic HTML5; skip-to-content link preserved
